# Paleta oficial LexFlow (definida pelo Diogo, 2026-08-26)

Deve substituir a paleta JMASSANO nos templates de email (src/lib/emails/moldura.ts) e estar disponível para o styling por sociedade.

| Elemento | Hex | Pantone |
|----------|-----|---------|
| Dourado (Gold) | #C9A053 | 7408 C |
| Cinza escuro (Dark gray) | #2F3138 | 432 C |
| Branco (White) | #F2F2F2 | — |
| Cinza claro (Light gray) | #B7B7B7 | Cool Gray |

Mapa para o moldura.ts atual:
- `TINTA` (#101a24) → Cinza escuro **#2F3138**
- `MARCA` (#d9694b, terracota) → Dourado **#C9A053** (acento principal / botões de ação)
- `ARQUIVO` (#2f5d50) → Dourado **#C9A053** (CTA positivo)
- `SELO` (#8c2f39) → Cinza escuro **#2F3138** (má notícia)
- `LATAO` (#a9884f) → Dourado **#C9A053**
- `PAPEL` (#edefea) → Branco **#F2F2F2**
- `PAPEL_ALTO` (#ffffff) → Branco **#F2F2F2**
- `LINHA` (#d6dad2) → Cinza claro **#B7B7B7**

Nota: aplicar quando o rebranding (marca LexFlow) estiver concluído, ou em conjunto.
