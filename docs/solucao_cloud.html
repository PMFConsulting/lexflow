Porquê a recomendação

  • Hetzner Storage Box — o melhor custo por terabyte na UE, com RGPD nativo (dados na Alemanha/Finlândia) e verificação de integridade automática.
  • Storage Share — se a equipa precisar de aceder e partilhar os dossiers como num drive privado (Nextcloud), com backups automáticos.
  • Estratégia 3-2-1 — 3 cópias dos dados, em 2 meios diferentes, 1 fora do escritório (cloud) — a regra de ouro para conteúdos críticos.

Desenho técnico · três camadas

Arquitetura recomendada

Uma camada extra de segurança para conteúdos muito importantes — combina a infraestrutura existente com cloud externa.

01
Servidor principal
Os dossiers ativos e a aplicação correm no servidor da sociedade (VPS), com pastas dedicadas por cliente.
02
Backup local
Cópia diária automática num segundo disco do servidor.
03
Backup cloud externo
Cópia encriptada fora do escritório (Hetzner Storage Box) — proteção contra incêndio, roubo ou falha total do servidor.
Encriptação
Os dados são cifrados antes de sair do servidor (chave gerida pela sociedade) — nem o fornecedor cloud consegue ler os ficheiros.
Retenção
Política de guarda dos dossiers conforme as obrigações legais do escritório.

Segurança e conformidade

  • RGPD — dados em datacenters da UE (Alemanha/Finlândia), sem transferência para países terceiros.
  • Sigilo profissional — encriptação em trânsito (TLS) e em repouso, com acesso controlado e registo de atividade.
  • Auditoria — cada acesso aos dossiers fica registado com a cadeia de integridade.
  • Recuperação — restauro testado periodicamente para garantir que os backups funcionam quando forem precisos.
Valores verificados (2026): Hetzner Storage Box desde ~3,80 €/TB/mês (hetzner.com); Backblaze B2 6 USD/TB/mês (backblaze.com); OVHcloud Object Storage 0,01 €/GB/mês sem taxas de transferência (ovhcloud.com); AWS S3 ~0,023 USD/GB + egress 0,09 USD/GB (aws.amazon.com).
