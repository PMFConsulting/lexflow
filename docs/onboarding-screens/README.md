## Convenção de nomes

Coloca um ficheiro por passo, com estes nomes exatos:

```
passo-1-identificacao.png
passo-2-fiscal.png
passo-3-representante-legal.png
passo-4-ppe.png
passo-5-rgpd.png
passo-6-faturacao.png
passo-7-fecho-assinatura.png
```

`.png` ou `.jpg`, ambos servem. Se um passo tiver ecrã longo e precisares de o
partir, acrescenta um sufixo: `passo-1-identificacao-a.png`, `-b.png`.

## Notas

- Se o formulário atual tiver variantes (particular vs. empresa), envia as duas —
  a ramificação do passo 1 é o que decide metade do schema.
- Screenshots com dados reais de clientes **não devem** ser commitados. Se os que
  tens contiverem dados reais, tapa-os ou usa dados fictícios antes de os pores aqui.
  Esta pasta está a ser versionada no repositório.
